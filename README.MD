### Instruções para importar o database:

- Colocar o tema na pasta /app/public/wp-content/themes.
- Ativar o tema e criar as páginas selecionando os modelos corretamente.
- Importar a base de dados no phpmyadmin ou AdminNeo.
- Substituir as url's onde for necessário.
- Os links: Quem somos, FAQ, Contato e Painel Administrativo estão utilizando um url inserido manualmente nas opções de menu do wordpress, é necessário trocar caso não esteja fucionando corretamente.
